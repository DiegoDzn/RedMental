# RedMental
**Aplicación que registrará el tránsito de pacientes para llegar a consulta en psiquiatría**

---

### Problemática
El tránsito de una persona por la atención psiquiátrica de adultos suele ser fragmentado: 
* La información clínica se pierde en cada reinicio de la historia.
* No se registran los puntos donde el paciente abandona el sistema.
* Las recaídas se atribuyen erróneamente a la falta de adherencia del paciente en lugar de a discontinuidades del propio sistema de salud.

### Objetivo general
Diseñar un sistema tecnológico (modelo de datos, flujograma o prototipo de interfaz) que permita a médicos y residentes registrar y visualizar el tránsito completo del paciente por la red de salud mental, detectando en tiempo real los puntos donde se pierde información o continuidad.
